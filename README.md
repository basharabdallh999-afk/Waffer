# منصة وتطبيق وفر (Waffer) 🛍️🇾🇪
### النظام المتكامل لإدارة واستعراض عروض وتخفيضات المراكز التجارية في صنعاء

منظومة برمجية متكاملة تجمع بين:
1. **تطبيق موبايل تفاعلي وعصري (Flutter)**: للعملاء والمتسوقين وأصحاب المتاجر.
2. **لوحة تحكم وإدارة ويب متقدمة (ASP.NET Core MVC)**: لمدير المنصة لمتابعة الإحصائيات، وتوثيق المتاجر، والتحكم بالبنرات الإعلانية.
3. **واجهة برمجية سريعة وآمنة (ASP.NET Core Web API)**: وفق معمارية Clean Architecture لربط كافة العمليات بقاعدة بيانات SQLite.

---

## 🌟 أبرز مميزات النظام

- **دورة انضمام وتوثيق المتاجر**:
  - تسجيل التاجر عبر التطبيق ببيانات متجره.
  - إشعار فوري لمدير المنصة بطلب الانضمام الجديد.
  - مراجعة وتوثيق المتجر أو رفضه من لوحة تحكم الويب.
- **إدارة صلاحيات النشر والإيقاف**:
  - إيقاف المتجر عن نشر العروض لفترة مؤقتة (محددة بالأيام) أو إيقاف نهائي مع ذكر سبب الإيقاف.
  - تنبيه المتجر بحالة الإيقاف وتاريخ انتهائه فوراً في التطبيق مع حماية برمجية كاملة (`HTTP 403 Forbidden`).
- **الإعلانات والبنرات المميزة (Sponsored Carousel)**:
  - صلاحية حصرية لمدير النظام لتحديد وترقية العروض كإعلانات مميزة مدفوعة مع تحديد أولوية الظهور (`Display Priority`).
  - شريط إعلاني دوار يتحرك تلقائياً كل 3 ثوانٍ في واجهة التطبيق الرئيسية مع شارة `إعلان مميز مدفوع ★`.
- **تجربة مستخدم راقية (UI/UX)**:
  - واجهة تسجيل دخول ثلاثية التبويبات (تسجيل دخول، حساب شخصي، حساب تاجر) مع إمكانية التصفح السريع كزائر.
  - قائمة جانبية (Drawer) تفاعلية تحتوي على شاشات العروض، المفضلة، تفاصيل التطبيق ومعلومات المساعدة.

## 🚀 تعليمات التشغيل (How to Run)

### 1. تشغيل الباك إند ولوحة التحكم (.NET):
```bash
cd basharfinal
# تشغيل الـ API:
dotnet run --project SanaaOffersApi.API --launch-profile http
# تشغيل لوحة تحكم الويب MVC:
dotnet run --project SanaaOffers.MVC --launch-profile http
```
- رابط الـ API و Swagger: `http://localhost:5232/swagger`
- رابط لوحة تحكم الويب: `http://localhost:5069`

### 2. تشغيل تطبيق الموبايل (Flutter):
```bash
cd sanaa_offers_app
flutter pub get
flutter run
```
